# Product Service

REST API for managing products, built with Java and Spring Boot.

## Tech Stack

* Java 25
* Spring Boot
* PostgreSQL
* Gradle
* Docker Compose
* Testcontainers
* JUnit 5

## Features

The service provides endpoints for:

* Creating a product
* Retrieving a product by its unique code
* Retrieving a list of products

When creating a product, the EUR price is converted to USD using the HNB exchange rate API.

Products contain:

* `id` – database identifier
* `code` – unique 10-character product code
* `name` – product name
* `priceInEur` – product price in EUR
* `priceInUsd` – product price in USD, calculated using the HNB exchange rate
* `available` – product availability

## Requirements

To run the application locally, you need:

* JDK 25
* Docker / Docker Compose

## Configuration

The application requires an API key for accessing the REST API.

Configure the API key using an environment variable:

```yaml
product-service:
  security:
    api-key: ${API_KEY}
```

The HNB API URL is configured as:

```yaml
product-service:hnb:
  hnb:
    api:
      url: https://api.hnb.hr/tecajn-eur/v3
```

## Running the Application

Clone the repository:

```bash
git clone <repository-url>
cd product-service
```

Start PostgreSQL using Docker Compose:

```bash
docker compose up -d
```

Make sure the `local` Spring profile is active when running the application.

Or simply start the application, and Docker Compose will be started automatically by Spring Boot using spring-boot-docker-compose:

Start the application:

```bash
./gradlew bootRun --args='--spring.profiles.active=local'
```

The application will be available at:

```text
http://localhost:8080
```

## API

All endpoints are available under:

```text
/api/v1/products
```

### Authentication

The API uses an API key for authentication.

Include the following header with each request:

```http
X-API-KEY: your-secret-api-key
```

### Create Product

**POST** `/api/v1/products`

Request:

```json
{
  "name": "Test product",
  "priceEur": 12.34,
  "available": true
}
```

Response:

```json
{
  "code": "2r8AxZRDsk",
  "name": "Test product",
  "priceInEur": 12.34,
  "priceInUsd": 14.38,
  "available": true
}
```

The product code is generated by the application and is exactly 10 characters long.

The USD price is calculated using the current USD exchange rate retrieved from the HNB API.

### Get Product

**GET** `/api/v1/products/{code}`

Example:

```http
GET /api/v1/products/2r8AxZRDsk
X-API-KEY: your-secret-api-key
```

Response:

```json
{
  "code": "2r8AxZRDsk",
  "name": "Test product",
  "priceInEur": 12.34,
  "priceInUsd": 14.38,
  "available": true
}
```

### Get Products

**GET** `/api/v1/products`

Example:

```http
GET /api/v1/products
X-API-KEY: your-secret-api-key
```

Response:

```json
[
  {
    "code": "2r8AxZRDsk",
    "name": "Test product 1",
    "priceInEur": 12.34,
    "priceInUsd": 14.38,
    "available": true
  },
  {
    "code": "ABC123xyz9",
    "name": "Test product 2",
    "priceInEur": 20.00,
    "priceInUsd": 23.30,
    "available": false
  }
]
```

## Validation

Product creation validates the following fields:

* Product name must not be blank.
* EUR price is required.
* EUR price cannot be negative.
* Product code is generated automatically and must contain exactly 10 characters.
* EUR and USD prices are stored with two decimal places.

Example of an invalid request:

```json
{
  "name": "",
  "priceEur": -10.00,
  "available": true
}
```

The API returns a validation error instead of creating the product.

## Database

PostgreSQL is used for persistence.

Database schema changes are managed with Flyway migrations.

The application uses a PostgreSQL sequence to generate product IDs.

## Error Handling

The API uses appropriate HTTP status codes for common errors, including:

* `201 Created` – product successfully created
* `200 OK` – successful GET request
* `400 Bad Request` – invalid request data
* `404 Not Found` – product does not exist
* `503 Service Unavailable` – HNB exchange rate service is unavailable

## External API

USD exchange rates are retrieved from the Croatian National Bank (HNB) API:

```text
https://api.hnb.hr/tecajn-eur/v3?valuta=USD
```

The middle exchange rate (`srednji_tecaj`) is used for EUR → USD conversion.
